# Streamit Android downloads

Public Android prerelease APKs, matching preferred-source packages, notices and checksums are attached to Releases.

The selected Streamit/SLC-owned Android integration and release glue is licensed under GPL-3.0-or-later. Separately licensed component files retain their original terms, exceptions, notices and copyright owners. Read the release source package's LICENSE.md, COPYING and component notices for the exact scope. This is not a repository-wide relicensing of unrelated Streamit/SLC code.

Experimental prereleases are not an all-format or hardware certification. Version5-to6 in-app update and version6 physical codec/engine checks remain pending. Account/provider setup is required; relay-backed TorBox playback requires the configured PC relay.

No signing keys, credentials or private application data are distributed. This repository contains public distribution metadata only; the matching selected source is in each release's source archive.
